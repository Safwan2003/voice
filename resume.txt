RESUME FILE — Sales Outreach Voice Agent (SDR Colab Prototype)
================================================================

WHAT THIS PROJECT IS
---------------------
A single Google Colab notebook (colab/sdr_voice_agent.ipynb — moved here
from the repo root; still git-ignored) implementing a fully
self-hosted, conversational outbound-SDR voice agent using LiveKit Agents:
- STT: whisper-large-v3-turbo via faster-whisper (in-process)
- LLM: Qwen2.5-7B-Instruct served by Ollama (localhost:11434, OpenAI-compatible)
- TTS: OmniVoice (k2-fsa), in-process
- Room/signaling server: self-hosted livekit-server, exposed via two ngrok
  TCP tunnels (7880 signaling, 7881 ICE/TCP media), since Colab has no
  public inbound networking.
- Tested manually via LiveKit's hosted Agents Playground (no custom UI).

HOW TO RESUME
--------------
This was being executed with the superpowers:subagent-driven-development
skill (fresh implementer subagent per task, task-reviewer subagent after
each, dispatched from the main session — NOT a separate background
process). To pick back up:

1. Invoke Skill "superpowers:subagent-driven-development" again (or just
   ask Claude to "continue executing the SDR voice agent plan").
2. Read .superpowers/sdd/progress.md — every task listed there as
   "complete" is done; do NOT re-dispatch it.
3. Resume at the first task NOT marked complete in the ledger (see status
   below).
4. Per task: run
     scripts/task-brief docs/superpowers/plans/2026-07-06-sdr-voice-agent-colab.md N
   (script lives in the subagent-driven-development skill's scripts/ dir),
   dispatch a fresh implementer subagent with that brief, then generate a
   review package with scripts/review-package BASE HEAD and dispatch a
   task-reviewer subagent. Loop fix->re-review until approved, then append
   a line to the ledger and move to the next task.
